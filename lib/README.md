# JDBC driver

Put the MySQL Connector/J jar in this folder (it is not committed to Git).

Download (Maven Central):
https://repo1.maven.org/maven2/com/mysql/mysql-connector-j/8.4.0/mysql-connector-j-8.4.0.jar

Any 8.x release of `mysql-connector-j` works. The file name does not matter, as long as it ends in `.jar`.

Using Maven instead? You do not need this folder: `pom.xml` already declares the dependency.
